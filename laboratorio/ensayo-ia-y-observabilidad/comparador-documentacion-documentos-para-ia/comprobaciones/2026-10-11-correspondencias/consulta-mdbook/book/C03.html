# R-C-INCIBE

## P-C01

■ Adaptive Authentication and Robust MFA. Implement mandatory multi-factor authentication (MFA/2FA) for all access points (especially remote and third-party access).
Phishing-resistant methods (such as physical keys or FIDO2) should be prioritized over SMS or traditional codes, which can be intercepted or bypassed through automated man-in-the-middle attacks.

## P-C02

■ Zero Trust Architecture. Eliminate implicit trust within the network. Each access request must be continuously verified based on context (device, location, behavior), limiting the movements of potential autonomous AI agents that could breach the perimeter.

## P-C03

In any case, these measures and recommendations do not replace the best practices that have been implemented by this entity, such as authentication of internal and external users, software security, perimeter defense, backup systems, etc., but rather reinforce and/or complement them.
