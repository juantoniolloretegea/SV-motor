# Servicio documental MCP

El prototipo proporciona dos herramientas: `buscar_documentos` y `leer_documento`. Opera sobre un catálogo local de documentos conservados. La adquisición documental es una operación administrativa separada.

| Versión | Contenido | Estado |
|---|---|---|
| [0.1.0](0.1.0/) | Código Rust, dependencias fijadas, catálogo, fuentes y evidencias | Preparación incompleta |

El [estado técnico de 0.1.0](revisiones/0.1.0-revision-02/ESTADO_TECNICO.md) identifica las limitaciones y las comprobaciones pendientes. El [paquete original](0.1.0/SV-MCP-DOCUMENTAL-0.1.0-20260926.tar.gz) y su [manifiesto](0.1.0/MANIFIESTO_VERSION_SHA256.json) se conservan sin alteración.

La disponibilidad de estos materiales no acredita conformidad completa, integración con el motor ni uso efectivo por el modelo.

## Seguimiento técnico

La [ficha técnica del componente](FICHA_TECNICA.md) y el [TT-0014 vinculado a S39](https://github.com/juantoniolloretegea/SV-lenguaje-de-computacion/blob/main/docs/calidad/Inventario-sv/tiques-tecnicos/TT-0014.md) delimitan la preparación de una consulta documental local, su trazabilidad y sus criterios de recepción. El tique está pendiente; su publicación no acredita una corrección ejecutada ni una nueva prueba con el modelo.
