# Anthropic · plataforma gestionada · nodo 02

Este directorio conserva las condiciones, realizaciones y evidencias de los modelos de Anthropic examinados mediante una plataforma gestionada. Cada modelo tiene un expediente propio; compartir proveedor no implica compartir versión, acceso, controles o resultados.

El [expediente de Claude Opus 5.5](claude-opus-5-5/readme.md) identifica la modalidad utilizada en Kaggle Benchmarks y separa comprobación de acceso, preparación técnica, evaluación documental y recepción independiente.

El nodo 02 corresponde a experimentación en una plataforma gestionada. Sus permisos, cuotas, transporte y observabilidad deben acreditarse en cada realización; no se trasladan automáticamente las garantías de una instalación propia ni las de una API directa. Los pesos y la infraestructura de inferencia permanecen bajo gestión del proveedor. Las evidencias científicas se conservan en este repositorio; los importes y las fuentes administrativas se archivan en su sede privada competente.

Las versiones históricas y los resultados de otros candidatos permanecen separados. Una prueba documental no acredita aptitud clínica ni un sistema operativo de ciberseguridad.
