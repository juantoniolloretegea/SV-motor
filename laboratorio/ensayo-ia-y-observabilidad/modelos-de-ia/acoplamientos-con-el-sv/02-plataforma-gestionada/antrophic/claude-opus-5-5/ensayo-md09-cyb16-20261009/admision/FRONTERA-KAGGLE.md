# Admisión de la frontera Kaggle para Claude Opus 5.5

09/10/2026. Preparación; ninguna inferencia científica al corte.

La biblioteca oficial Kaggle `01183088103937114b723b82b8d5ea0c7a87ccce`, ModelProxy y proxy_openai, fija Chat Completions y desactiva el flujo. Describe trazas dentro de etiquetas iniciales <think> y mensajes nulos ocasionales. El transporte Rust conserva íntegros los bytes HTTP, el contenido original, canales adicionales, texto final, intervalos de separación y contadores originales. No usa la biblioteca Python para inferir. La adaptación no cambia el núcleo, su semántica, IR ni los criterios científicos; se identifica el formato efectivamente enviado.

Mensajes históricos completos por pregunta; esfuerzo high; cota 16384 tokens; salida JSON con esquema científico y declaración operativa separada; sin herramientas, temperatura añadida, evaluadores auxiliares ni reintentos. El formato estructurado está declarado como admitido para este candidato por la biblioteca oficial; su recepción efectiva todavía debe comprobarse. R2 es final sin selección retrospectiva. Al producirse una recepción incompleta, falta de coste o fallo de medición, se conservan originales y se impide continuar.

El MCP mdBook se ejecuta en Rust antes del suministro al candidato. Manual: cuatro documentos/31 secciones; CYB16: cinco documentos/28 secciones. Se conservan solicitudes, respuestas, aislamiento, huellas y diario de cada banco. El candidato recibe el corpus íntegro ya suministrado; no se atribuyen a Claude llamadas autónomas al MCP. Las consultas son documentales, sin pacientes ni intervención clínica.

La medición externa identifica únicamente el proceso Rust: reloj monotónico, CPU, memoria, E/S y conexiones por PID; intervalo objetivo 250 ms. Se mide recepción de cabeceras y primer byte del cuerpo, no primer token del modelo. No se observa hardware remoto, procesos internos, DNS/TLS separados ni estados privados. Lo declarado por el candidato permanece separado de medición y contadores del servicio. Desconocidos se consignan null.

Sólo cuota existente: límite inicial 9,99 USD, menor que los 9,99196275 USD calculados tras descontar los 0,00803725 USD ya registrados. La cuota actualizada muestra 0,01/10 USD y 0,01/100 USD; se respeta también el margen visible redondeado. Reserva conservadora antes de cada envío: un token por byte UTF-8 más 4096 de margen de entrada, a 4 USD/millón; 16384 de salida a 20 USD/millón. Es reserva de protección, no liquidación ni afirmación del tarifario Kaggle. Consumo efectivo desde nanodólares comunicados por el servicio. Sin compras, ampliaciones ni compensación de desconocidos por cero. Comprobar saldo visible antes del inicio; detener ante desviación.

Compatibilidad de compilación: Rust Linux disponible inicialmente 1.93.1, insuficiente para sysinfo 0.39.6 (mínimo 1.95). Se incorpora Rust 1.98.1, edición mínima, desde la distribución oficial Rust, aislado dentro del perímetro y sin modificar PATH ni el compilador general. Se conserva Cargo.lock. La biblioteca criptográfica ring ya autorizada sigue identificada como dependencia nativa de comunicaciones; no se presenta como Rust puro. Fuente de instalación: https://rust-lang.github.io/rustup/installation/index.html.

Recepción pendiente: ejecución Linux, admisión instrumental sin inferencia, primera entrega ordinaria y posterior campaña. Una comprobación local no acredita aceptación del servidor. La preparación inicial interrumpida por restricciones WSL permanece separada, sin resultado científico ni coste de candidato comunicado.
