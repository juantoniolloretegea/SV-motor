# Qwen · Nodo 03 · API directa de Alibaba Cloud

[Qwen3.8-Max-0902: expediente experimental](qwen3.8-max-0902/readme.md). Acceso técnico comprobado el 08/10/2026; examen documental en curso, todavía sin dictamen.

Alibaba ejecuta la inferencia. El SV conserva el Árbitro-Director, la fuente documental, las instrucciones, la instrumentación y la recepción. Este emplazamiento corresponde al [nodo 03](../readme.md); se distingue de los modelos alojados en recursos propios del nodo 01.
