# Inventario de elementos utilizados y límites

| Elemento | Evidencia y responsabilidad |
|---|---|
| Árbitro-Director documental Rust | Agenda, identidad, fuentes congeladas, separación de corrección y tres etapas; controlador común sin alterar durante el examen |
| MCP Rust | Cinco secciones completas; reconstrucción y huellas; aislamiento local de sockets. El intento preliminar impedido por restricción WSL no produjo inferencia |
| Cliente común Rust | HTTPS Responses, perfil restringido, fuente exclusiva, licencia, recepción progresiva y terminal |
| Instrumentación Rust | Proceso propio, CPU, memoria, E/S, conexiones TCP/UDP, puertos y estados; objetivo de muestreo 250 ms y máximo observado 378 ms |
| Control de consumo Rust | Reserva conservadora de tokens antes del envío; usage recibido; bloqueo de pago Stop-on-Exhaust comprobado en el proveedor |
| Acotación Rust | Identidad del proceso y corte tras I048; consolidación de los 48 hitos originales y rechazo de intentos adicionales |
| Receptor Rust | Concordancia SSE/texto, HTTP, restricciones, integridad de fuentes y agregación sin duplicar subtotales |
| Revisión exterior | Cotejo semántico asistido por IA; clave reservada separada. El candidato no califica su propia entrega |
| Adjudicador Rust | Recibe la revisión exterior, valida identidad, forma, símbolos, alcance, criticidades y veto. Cinco comprobaciones unitarias conformes |
| Visor Rust/egui | Pareja matemática y visual derivada de la adjudicación completa; doce comprobaciones de radios, colores, interacción, alertas, integridad y veto conformes |
| Custodia Rust | Comparación por contenido y SHA-256 de las publicaciones recuperadas; distinta de subir archivos |

Se conserva la dependencia criptográfica nativa admitida para el experimento. Los apoyos editoriales no ejercen decisiones ni controles del SV. No se usa Python como componente del recorrido. No se atribuye al comprobador mecánico competencia clínica ni capacidad para detectar intenciones del modelo.

Los originales operativos completos permanecen en custodia local privada: solicitudes, perfiles, eventos y telemetría de direcciones. La publicación contiene derivados científicos sin credenciales, cuenta, saldos, clave de corrección ni direcciones operativas. No se afirma custodia remota íntegra de esos originales.
