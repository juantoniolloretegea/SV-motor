# Inventario de realización y límites

| Componente | Utilización efectiva |
|---|---|
| Controlador diagnóstico Rust | P13 exclusivamente, tres etapas, fuentes congeladas, límite de cuota y máximo de intentos |
| Suministro MCP Rust común | Recuperación íntegra, secuencia RPC, diario y huellas; comprobación local de ausencia de sockets |
| Contrato documental común | Esquema, contexto histórico completo y contraste literal de citas |
| Cliente HTTP Rust común | Perfil fechado, destino del proveedor, licencia, herramientas deshabilitadas y conservación SSE |
| Instrumentación Rust | Proceso, CPU, memoria, E/S, conexiones TCP/UDP, puertos, estados, eventos y tiempos |
| Recepción Rust común | Cotejo SSE/texto, contadores del proveedor, telemetría y restricciones devueltas |
| Revisión exterior | Contenido, suficiencia, restricción y fundamento; separada del candidato, asistida por IA |
| Receptor diagnóstico Rust | Verifica identidades de las tres revisiones y deriva conformidad por dimensión |
| Custodia Rust | Cotejo de bytes y SHA-256 tras recuperar las publicaciones |

Once comprobaciones del controlador y módulos comunes conformes antes de ejecutar. El receptor diagnóstico y el receptor general compilan conjuntamente. No se genera otro polígono para una sola pregunta ni se modifica el existente. Los apoyos editoriales preparan documentos y publicaciones; no realizan el control, suministro ni medición del SV.

Los originales operativos, perfiles, solicitudes y telemetría de direcciones quedan en custodia privada local. No se afirma que estén publicados íntegramente. Código publicado con sustitución documentada de la raíz de instalación; esa versión no es el ejecutable medido. Las fuentes históricas y los resultados anteriores permanecen intactos.
