# GLM-5.3 · API directa · Nodo 03

**Estado a 08/10/2026: candidato en preparación; ninguna inferencia recibida ni dictamen emitido.** Se propone el identificador `glm-5.3` como candidato principal del proveedor. Su [ficha oficial](https://docs.z.ai/guides/llm/glm-5.3) no sustituye el examen del SV.

## Vía propuesta y límites

La vía inicialmente documentada es la [API general de Chat Completion](https://docs.z.ai/api-reference/llm/chat-completion), con dirección `https://api.z.ai/api/paas/v4/chat/completions`. El anuncio de disponibilidad de otros protocolos no acredita que el cliente común pueda utilizarlos sin adaptación y recepción previa.

Se propone conservar el [cliente común Rust](../../../cliente-api-rust/CONTRATO.md), incorporando únicamente el contrato específico que se apruebe. La realización actual admite otros proveedores mediante Responses; no admite todavía esta configuración. No se duplicará el Árbitro-Director ni se alterarán Núcleo, semántica V0.2 o IR 0.3.

El candidato recibirá exclusivamente instrucciones autorizadas, secciones documentales íntegras y antecedentes verificables. El suministro MCP permanecerá bajo control del SV. La clave de corrección, las mediciones, los controles y las credenciales no forman parte de su contexto. Ninguna herramienta de navegación, ejecución o acceso autónomo queda habilitada por esta preparación.

## Recepción pendiente

La adaptación debe comprobar por separado identidad, texto final, cierre, errores, contadores y tramas progresivas. La recepción conservará el original incluso ante rechazo o interrupción. Un fallo instrumental no se atribuirá automáticamente al modelo y no dará lugar a una nueva solicitud automática.

El esquema científico, los localizadores y las citas se comprobarán en Rust. Una salida declarada JSON no acredita conformidad sustantiva. La medición del proceso propio y del transporte tampoco acredita observación del cómputo interno del proveedor. No se solicitará razonamiento privado; se exigirán fundamentos y referencias comprobables.

GLM-5.3 requiere razonamiento activado. Para la futura campaña se propone intensidad `max`, pendiente de aprobación de sus condiciones. Quedan por contrastar los límites de salida y su relación con el razonamiento facturable. No se trasladarán sin examen opciones ni garantías de otro proveedor, incluida la equivalencia entre desactivar almacenamiento y retención nula.

## Condiciones de admisión

| Condición | Estado |
| --- | --- |
| Identidad inmutable o reserva explícita sobre el alias | Pendiente de recepción; no se ha acreditado una revisión pública fijada. |
| Contrato de transporte y controles específicos en Rust | Adaptación pendiente; deben preservarse los controles comunes. |
| Comprobaciones instrumentales sin acceso externo | Pendientes; incluir errores, fragmentación, límites e interrupciones. |
| Solicitud real mínima y uso conciliado | No realizada. |
| Alcance contractual y corpus autorizado | Reserva pendiente de resolución para el ensayo concreto. |
| Límite de consumo autorizado y efectivo | Dependencia de admisión; registro administrativo privado. |
| Campaña y evaluación | No iniciadas; no existe dictamen de aptitud. |

Las [condiciones adicionales de API](https://docs.z.ai/legal-agreement/terms-of-use) y el [anexo de tratamiento](https://docs.z.ai/legal-agreement/privacy-policy) deben cotejarse para el acceso concreto. Sus declaraciones sobre contenidos no constituyen una comprobación técnica. Debe resolverse asimismo la reserva sobre usos profesionales y decisorios antes de cualquier aplicación productiva. Esta preparación no habilita datos personales de pacientes ni presupone que la supervisión humana elimine restricciones contractuales.

La autorización y conciliación de consumo se conservarán en su sede privada. Las [tarifas oficiales](https://docs.z.ai/guides/overview/pricing) se revalidarán antes de una solicitud autorizada. No se atribuirá coste cero a una solicitud cuyo uso resulte desconocido. No se sustituirá la API general por una cuota de Coding Plan fuera de su [alcance permitido](https://docs.z.ai/legal-agreement/subscription-terms).
