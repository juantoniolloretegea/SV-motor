# Hito A06-A0 · Astra · Nodo 03

Incorporación retrospectiva de evidencias conservadas: originales, auditoría formal, adjudicación y medición cotejadas en Rust. No hubo otra inferencia ni modificación de puntuaciones. La fecha de derivación no se presenta como fecha del ensayo. Las adjudicaciones proceden de CAPA.json completo; no se fabrica un vector parcial histórico.

El manifiesto identifica todos los originales locales; su inclusión no declara que se haya publicado cada archivo. Se publican respuesta final, admisión, auditoría formal, adjudicación y medición resumida. Se conservan separados los recursos no observados del proveedor y los tokens comunicados. La recepción independiente permanece separada.
