## Estado y alcance

El lector organiza las representaciones Markdown mediante mdBook. El recorrido de entrega comprobado prepara fragmentos de texto; no acredita todavía el envío directo de originales PDF o HTML, aunque ambos formatos son admisibles con autorización. La representación gráfica íntegra del PDF y el tratamiento integral de libros extensos siguen pendientes.

La autorización corresponde exclusivamente al administrador o al Proveedor de documentos para la IA. El formato, la conversión y la visualización no conceden esa autorización.

El libro es la explicación pública. La información particular de un documento y de una consulta permanece en el entorno autorizado. La lectura desde la administración enlaza la misma edición de la biblioteca; no transmite documentos ni identificadores reservados al abrirla.

Esta carpeta conserva las fuentes editoriales del libro para auditoría. La copia de publicación en la Biblioteca del SV debe corresponder exactamente a estas fuentes, con versión y huellas verificadas. No contiene credenciales, configuraciones privadas, expedientes particulares ni bibliografía reservada.
